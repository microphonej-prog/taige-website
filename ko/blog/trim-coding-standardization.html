부자재 코딩과 판 라이브러리 표준화: 행택·직조 라벨·세탁 표시 라벨 재사용

TAGE 패키징 · 2026년 9월 29일 업데이트

부자재는 수량과 금액이 작아 관리 주체가 없기 쉽고, 2~3년 뒤에는 같은 행택에 네 세트의 판, 같은 메인 라벨에 세 개의 색상 번호, 재발주 시 승인 샘플을 찾지 못하는 상황이 됩니다. 부자재 코딩과 판 라이브러리 표준화는 행택·직조 라벨·세탁 표시 라벨·포장 백을 번호와 담당, 보관 샘플을 가진 '표준 부품'으로 만드는 작업입니다. 재발주와 배색, 공급처 변경이 기억에 의존하지 않게 됩니다.

이 글은 바로 옮겨 쓸 수 있는 코딩 규칙, 판 대장에 등록할 항목, 색상 카드 라이브러리 운영 방식, 그리고 코드를 사양서와 발주서에 적어 공급처와 같은 언어로 일하는 방법을 제시합니다.

1. 부자재가 엉키는 세 가지 원인

  • 고유 번호 없음: 같은 행택을 디자인은 '블랙골드 행택', 구매는 'SK26 행택', 공장은 '지난달 그거'라고 부릅니다
  • 판 라이브러리와 소유권 없음: 인쇄판, 칼금형, 자카드 문판이 여러 공장에 흩어져 있고 누가 보관하는지 알 수 없어 재발주 시 판을 다시 뜹니다
  • 색상 번호 없음: '오프화이트', '크림', '아이보리'를 사람마다 다르게 쓰고 공장이 자체 해석으로 조색해, 같은 품번이 시즌 간 눈에 띄는 색차를 만듭니다

2. 코딩 규칙 설계: 5단계 구조

좋은 코드는 복잡할 필요가 없고 각 구간의 의미만 고정되면 한눈에 읽힙니다. '카테고리—소재·공정—규격—색상—버전' 다섯 구간을 하이픈으로 구분하고 영문 대문자와 숫자만 사용합니다.

구간의미예흔한 실수
1구간: 카테고리행택 HT, 직조 라벨 WL, 세탁 표시 라벨 CL, 비닐백 PB, 종이백 PBG공장 자체 호칭을 써서 공급처가 바뀌면 통하지 않음
2구간: 소재·공정KRA 크라프트, ART 아트지, CTN 면지, SAT 새틴, TFL 능직 자카드, FOIL 박같은 소재에 두 가지 약어가 생겨 대장이 흐트러짐
3구간: 규격밀리미터 숫자만: 9054는 90×54mm, 직조 라벨은 폭과 접힘으로 30F는 30mm 센터 폴드단위와 표기 혼용(90X54 / 9×5.4 / 대형)
4구간: 색상통제된 색상표와 코드: BLK 검정, WHT 흰색, NAT 내추럴, PNT123은 지정 Pantone형용사로 색상 지정(조금 더 진한 검정)으로 실행 기준이 없음
5구간: 버전01부터 시작하는 두 자리. 개정 시 증가, 구버전은 폐기 표시하되 대장에 보존개정 후에도 같은 번호를 써서 공장이 신·구 버전을 혼용

이 규칙에서 90×54mm 크라프트지 검정 첫 버전 행택은 HT-KRA-9054-BLK-01입니다. 한 번 읽으면 내용이 파악되고, 메일·사양서·발주서·창고 라벨에 같은 문자열을 씁니다.

3. 판 라이브러리 대장: 반드시 기록할 항목

대장의 목적은 하나입니다. 어떤 부자재든 언제든 누구나 '판이 어디 있고, 쓸 수 있는지, 재발주에 며칠 걸리는지'에 답할 수 있어야 합니다. 아래 항목이 하나라도 빠지면 대장은 서서히 신뢰를 잃습니다.

  • 코드와 명칭: 공식 코드와 검색하기 쉬운 통칭을 모두 등록
  • 판 종류와 수량: 인쇄판, 박판, 칼금형, 엠보형, 자카드 문판, 스크린 판을 각각 명시
  • 보관 위치: 어느 공장, 어느 기계 옆, 몇 번째 선반인지 한 번에 찾을 수 있게 기록
  • 소유권과 비용: 판 비용 부담자, 매입 완료 여부, 공급처 변경 시 회수 가능 여부. 분쟁이 가장 많은 항목입니다
  • 상태와 수명: 사용 가능, 보수 필요, 폐기 세 단계. 인쇄판과 칼금형은 사용 횟수 한도가 있고 초과하면 로트 편차가 생깁니다
  • 승인 샘플 사진과 실물: 실물은 최소 두 점, 브랜드와 공장에 각각 한 점. 사진은 날짜와 함께 보관합니다

4. 색상 카드 라이브러리: 색을 재사용 자산으로

부자재 색상은 면적이 작고 소재가 안정적이어서 원단보다 표준화가 쉽습니다. 상용 색상을 실물 색상 카드 라이브러리로 만들고 색마다 코드·카드·소재별 대조표를 두면, 다음에는 'NAT-03 사용'만 말하면 재조색이 필요 없습니다.

  • 색마다 실물 카드: 코드, Pantone 참조, 적용 지류·사, 제작일을 기재
  • 소재 간 대조표: 같은 색상 코드도 아트지·크라프트·새틴에서 다르게 보이므로 소재별 허용 편차를 명시
  • 표준 광원에서 비교: 색상 라이브러리는 D65 등 고정 광원이나 북향 자연광에서 비교하고 천장등 아래에서 판단하지 않음
  • 지속적 유지: 시즌마다 색상 카드를 추가하면 코드 대장과 대조표를 갱신하고, 단종 색상은 사용 중지로 표시하되 기록은 남겨 구주문 추적에 대비합니다

5. 사양서와 발주서에 반영: 공급처도 같은 언어로

  • 사양서 상단에 코드: 최상단과 하단에 함께 적어 전달 과정에서 버전 혼동을 막습니다
  • 발주 라인에 코드+버전: 예: HT-KRA-9054-BLK-01. 공장이 라인별로 확인 회신하면 구두 확인보다 훨씬 안전합니다
  • 판 폐기는 문서로: 구버전 폐기 시 공식 통보를 보내고 회신을 보관해, 나중에 구버전으로 생산해 손해가 발생하는 일을 막습니다
  • 입고 라벨 동기화: 선반 라벨, 바코드, 시스템 품번이 같은 코드를 가리키면 재고 실사에서 착오가 없습니다

6. 도입 3단계와 흔한 저항

  1. 코드 먼저, 정리는 나중: 완벽한 대장을 기다릴 필요가 없습니다. 생산 중인 20~30개 부자재에 코드를 부여하고 사양서와 발주서에 넣은 뒤 항목을 채워가면 석 달짜리 시스템 구축보다 빠릅니다
  2. 한 품목부터 시범: 색상 문제가 가장 크고 재발주가 잦은 부자재(대개 행택이나 메인 라벨)를 골라 코드·색상 카드·승인 샘플·대장을 한 시즌 운영한 뒤 세탁 표시 라벨과 포장 백으로 확대합니다
  3. 구매 프로세스에 코드를 넣기: 코드 없는 구매 요청은 견적 단계로 넘기지 않습니다. 이 한 규칙이 어떤 제도보다 효과적이고 두세 시즌이면 정착합니다
💡 팁: 가장 큰 저항은 기술이 아니라 '지금도 어떻게든 된다'는 생각입니다. 한 시즌을 기준선으로 삼아 색상 번호 불명확, 판 미확보, 재발주 시 판 재제작으로 생긴 추가 비용과 지연을 집계하면 어떤 제도 설명보다 설득력이 큽니다.
