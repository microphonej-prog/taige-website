Clothing Size Label Guide: Woven vs Printed Size Labels & Marking Tips

By TAGE Packaging  ·  Updated September 3, 2026

The size label is the smallest piece of the garment labeling system, yet it is looked up most often: shoppers hunt for it in stores, e-commerce buyers confirm it before ordering, and returns teams verify it. Wrong or unclear size marking directly drives up return rates. Behind every size label order there are really two decisions: woven or printed? And which country's size system should you follow? This size label guide answers both clearly.

1. The Role of the Size Label and Common Placements

A garment's labeling system usually consists of three labels: the main label (brand), the size label (size) and the care label (composition and care). The most common practice is to sew the size label next to the main label at the back neck so shoppers see it the moment they open the collar; trousers and skirts often carry it inside the waistband. Because size is the first thing people look for when opening a collar, the design rule for size labels is: large type, simple layout, readable at a glance — any size marking that needs squinting is quietly adding to your return rate.

2. Woven vs Printed Size Labels

AspectWoven size labelPrinted/heat-transfer size label
Feel & qualitySame weave as the main label — consistent and premiumThin and tagless; functional rather than premium
Size-change flexibilityRequires reweaving with new yarn colors; slower to changeChange the digits and reprint — almost zero cost per size change
DurabilityWoven from yarn; withstands washing and wear like the garmentDepends on ink and coating; watch for fading after many washes
Best useMid-to-high-end garments, stable size runs, matching main labelsFast fashion, small batches across many sizes, multi-country size codes

3. Size Systems Around the World and Marking Advice

MarketCommon MarkingAdvice
EULetter sizes XS–XXL, or numeric 34–52 depending on categoryFollow local conventions; avoid inventing your own system
US/CanadaMostly letters; women's often numeric 0–24North American sizes run large — verify with a target-market chart before export
UKWomen's numeric 6–20; men's lettersUK and EU numerics differ — never mix them
Asia (CN/JP/KR)Letters plus height/chest references (e.g. 160/84A)Asian sizes run small; switch systems entirely when exporting West
Children's wearBy age or height (e.g. 3Y, 92 cm)Age plus height is the most practical combination

A classic pitfall: selling EU numerics as US sizes, or vice versa. There is no universal conversion formula between markets, and even the charts held by factories and trim suppliers often disagree. The safe approach: use the size system of the market you export to, and have the brand confirm the size system and range in writing before ordering, archiving it with the size label artwork.

4. Multi-Size Layout and Production Tips

  • Center the size on the fold: size labels are often center-folded so only one size shows on the front — place the size in the folded center zone so the crease never cuts through digits
  • One-run multi-size production: woven labels can place all sizes XS–XXL side by side on one tape and be cut per size — one loom run covers the whole range at far lower cost than weaving each size separately
  • Print on demand: heat-transfer size labels have zero size-change cost — just edit the file; ideal for parallel country codes, trial orders and frequent reorders
  • Batch control per size: yarn lots and density must stay consistent within a size across runs to avoid shade variation; after cutting, pack per size with coded labels
💡 Tip: during trial orders, mix a woven main label with a printed size label: the main label locks in the brand image while the size label flexes with markets and runs — once your size system is fully stable, upgrade to an all-woven set for maximum quality and flexibility.

5. MOQ, Sampling and Cost Reference

Size label cost is driven by weave type, color count and the number of sizes: for woven size labels in a one-run multi-size layout, MOQ accumulates across all sizes (a thousand pieces is a common starting point), while printed/heat-transfer size labels offer more flexible MOQs for small trial runs. Sampling usually takes 3–7 days — request a matching set of woven main label plus size label, test-sew at the real position to confirm fold, type position and feel, then approve the sample before bulk. Adding size labels to one-stop sourcing with the same supplier as main and care labels also saves repeated shade-matching and follow-up costs.
