Trim Kitting Guide: Set Packing by Colour and Size

By TAGE Packaging  ·  Updated September 23, 2026

Trim kitting means shipping the hang tags, woven labels, care labels, size labels, strings, fasteners and packaging bags for a garment — or a whole order — bundled and packed by colour and size, instead of arriving in separate cartons per trim type. On paper it is only a packing difference; in practice it decides sorting hours, mismatched-trim rework and how fast goods can be checked in at the factory.

This guide runs through six steps — three levels of kitting, the costs it removes, control points, the data you need to prepare, packing and marking, and common questions — so you can use it directly when agreeing shipping terms with a trims supplier.

1. Three Levels of Kitting: From Sub-Packing to Piece-Level Sets

  • Level one · Split by colour and size: trims of one colour and one size go in one bag, with shade, size and quantity marked on the carton — best when the factory allocates trims from its own cutting tickets
  • Level two · Sets by colour and size: hang tag, woven label, care label and size label combined into one set per colour-size, one set per bag, so a single bag services one finished garment
  • Level three · Piece-level ratios against the cutting ticket: quantities per colour and size are calculated from the order's S/M/L/XL ratio and total piece count, so the sets match the order exactly

2. Which Factory Costs Kitting Removes

  • Sorting hours: no need to open several cartons per trim type and redistribute by colour and size — the line collects a bag instead of digging through boxes
  • Mismatch rework: with one set per colour-size, the chance of mixing labels drops sharply, taking rework and unpicking cost with it
  • Checking in: cartons are counted in sets, so receiving counts how many sets arrived instead of counting four material types separately
  • Stock and leftovers: set packing makes surplus obvious and cuts the dead stock that builds when tags run out while labels pile up

3. Control Points: Set Completeness, Allocation and Shortfalls

  • Put completeness in the contract: specify something like a set completeness rate of at least 99.5% and agree how shortfalls are replenished — far more workable than a vague plus or minus 3% count tolerance
  • Add margin where it breaks: trims that get damaged on the line — tag strings, care labels — usually travel with a small percentage over, so the last few garments are not held up
  • Agree the shortfall rule up front: decide in advance who pays for express replenishment, and whether a same-colour substitute is acceptable — settling it before shipping saves days
  • Align allocation with the cutting ticket: a ratio that does not match the cutting ticket is the most common kitting failure — have both sides sign off the ratio table before the order is confirmed

4. Data and Documents to Prepare

  • Trim bill of materials: which trims a style uses, with specification and quantity — the starting point for every kitting calculation
  • Colour-size matrix: brand colour code, fabric dye lot and trim colour code mapped to each other so same-colour different-batch drift is caught early
  • Ratios and totals: the proportion of each colour-size, the total piece count and any broken size runs, which decide how many sets to build
  • Packing and marking requirements: bag material and thickness, what goes on the inner label, carton mark format, and whether barcodes or QR codes are needed

6. Common Questions and How It Is Priced

  • Does kitting cost more? It adds labour and packing material — sorting, bagging, labelling — usually charged per set rather than as a percentage of trim value, and the rate depends on piece and set counts
  • Does kitting clash with MOQ? No. Each trim type is still produced at its own minimum, and kitting only changes the final packing stage, so smaller orders can start with basic sub-packing
  • What if the order changes mid-way? A ratio change ripples into sets already assembled, so the earlier you tell us the better; re-confirm the ratio table and keep a record of what already shipped
  • Can we kit only some of the trims? Yes. A common split kits hang tags with woven labels, and keeps care labels or packaging bags separate, depending on how the factory collects material
💡 Tip: the fragile part of kitting is never the bagging — it is the ratio table. Send us three columns — colour-size, piece count, set count — for a cross-check before ordering and you avoid most kitting errors.
