洗水標尺寸指南：常規規格、字高與版面規劃

泰閣包裝 · 更新於 2026年9月3日

洗水標尺寸是服裝輔料裏最容易被低估的細節：尺寸太小，纖維成分與洗滌符號排不下或被縫線喫掉；尺寸太大，貼身衣物硌人、縫製變形。更麻煩的是，出口標籤往往要到驗貨或上架階段才發現問題。這篇洗水標尺寸指南，從規格、字高到版面規劃，幫您一次把尺寸定對。

1. 先定類型與裝訂方式，再談尺寸

洗水標主要有三種形態，尺寸邏輯各不相同：織帶洗水標寬度受織機限制，常規爲 15mm、20mm、25mm（也有 10mm 與 30mm），長度按內容在 50–90mm 之間裁切，適合側縫等直線縫位；塗層/印刷洗水標與熱轉印洗水標沒有織機寬度限制，可做成 35×60mm、40×70mm 之類的矩形，也可以做成極窄的條狀，適合後中領、腰頭等位置。先和服裝廠確認裝訂方式與縫位長度，再倒推標籤尺寸，是最穩的順序。

2. 字高標準：既要合規，也要耐洗

洗水標上的每個字都要經歷數十次洗滌、烘乾與摩擦。實務經驗：拉丁字母（英文/法文等）高度建議不低於 1.5–2mm，中文不低於 2–2.5mm，洗滌符號按 ISO 3758（GINETEX）標準比例繪製，不能爲省空間隨意壓縮。合規層面，美國 FTC 要求護理標籤持久且清晰可讀（16 CFR 423），歐盟紡織法規要求纖維成分標籤耐久、易讀、可見、可及。字高不是設計偏好，而是合規與體驗的底線。

💡 提示：摺疊會讓可視字高「打折」——對摺後標籤厚度翻倍，縫在厚面料上時字會被撐變形。需要在折後仍保持 1.5–2mm 有效字高的，請把設計字高相應加大。

3. 內容決定行數，行數決定尺寸

內容項典型行數說明
品牌名/LOGO1 行可放正面或與主嘜合併
纖維成分1–2 行成分超過 4 種時建議兩行排布
洗滌符號組1–2 行符號需按 ISO 3758 比例完整繪製
原產地/進口商/RN號1–3 行美國市場可含 RN 號以隱藏廠名地址
護理說明短句1–3 行如「不可漂白」「懸掛晾乾」等
每增加一種語言+2–3 行多語言出口（如歐盟）需預留版面

估算方法很簡單：把內容逐行列出，數出行數上限。內容在 3 行以內的，單層或對摺即可；超過 3 行的，通常要加長織帶或改用多頁摺疊（書頁式），否則只能犧牲字高——而那是我們剛說過不能犧牲的東西。

4. 摺疊方式與長度規劃

  • 對摺（Center fold）：成品長度約爲裁切長度的一半，是最常見的縫製形式，適合內容在 3–6 行的標籤
  • 末端折（End fold）：兩端向中間折後再縫，看不到毛邊，適合需要精緻外觀的高端服裝
  • 書頁式（Booklet）：Z 形或 C 形多頁摺疊，每多一折長度約翻一倍，適合多語言、長內容的出口標籤
  • 長度規劃原則：裁切長度 = 成品可視長度 × 折數 + 縫份餘量；織帶越長單價越高，縫製難度也越大，夠用就好

5. 不同服裝品類的尺寸建議

品類推薦形態要點
T恤/襯衫對摺織帶 20×50–60mm側縫安裝，柔軟不硌
牛仔/工裝褲加長織帶 25×70–90mm內容多，水洗頻繁，需耐磨
童裝對摺 15×40–50mm短小柔軟，避免摩擦皮膚
外套/羽絨書頁式或加長帶多語言/長護理說明，內裏縫位空間足
內衣/運動貼身熱轉印或塗層標極薄無感，字高需嚴格校驗

6. 常見誤區與打樣確認

  • 誤區一：全品類統一用一種洗水標尺寸。外套與童裝對尺寸、柔軟度的要求完全不同，應按品類分別定規格
  • 誤區二：文字排到縫線邊緣。縫份會喫掉 3–5mm，四周務必預留安全邊距
  • 誤區三：先定稿再找位置。正確做法是讓服裝廠先確認縫位長度與摺疊形式，再據此定稿排版

尺寸問題靠打樣才能兜底：向供應商要 3–7 天的實物樣，用目標面料按真實縫位裝訂，再按標準洗滌 5 次，確認字跡清晰、無收縮變形、無散邊。批量尺寸公差通常控制在 ±2mm，封樣後把「封樣尺寸 + 公差」寫進合同，大貨就不會跑偏。
