吊牌尺寸规格指南：常规尺寸与异形模切

泰阁包装 · 更新于 2026年8月17日

吊牌尺寸规格直接决定印刷成本、挂绳方式和整体观感：同一张设计稿放到 35×70mm 与 60×100mm 上，气质完全不同。本文梳理常规吊牌尺寸、克重与厚度匹配、异形模切以及出血安全边距，帮您一次选对吊牌尺寸，少走打样弯路。

1. 常规吊牌尺寸一览

尺寸规格常见用途说明
35×70mm服装吊牌最常用长条形，信息区充足，性价比高
40×90mm外套、牛仔裤竖长形，适合品牌名加洗护提示
50×90mm中高端服装版面宽松，适合多语言信息
54×90mm国际品牌通用欧美市场常见，可容纳条形码
60×100mm奢侈品牌、礼盒装大幅面，适合烫金与触感工艺
圆形/异形童装、潮流品牌模切定制，形状即记忆点

2. 尺寸与吊牌用途如何匹配

选尺寸没有绝对标准，但有一条实用经验：信息量越大、品牌定位越高，吊牌尺寸越大。先列清楚吊牌上必须出现的内容——品牌名、LOGO、成分、产地、条形码或二维码、洗护提示——再估算所需版面。

  • 仅品牌名与简单视觉：35×70mm 足够，成本最低
  • 含成分、产地、条形码：建议 40×90mm 或 50×90mm
  • 电商防伪与二维码营销：推荐 54×90mm 以上，留出清晰扫码区
  • 异形吊牌：形状越复杂，模切刀版利用率越低，单价相应上升

3. 异形模切吊牌：形状即品牌

异形模切吊牌按刀模冲出特定轮廓，是低成本高辨识度的品牌记忆点。圆角、半圆开窗、服装轮廓、产品造型（鞋、帽、包）都能实现，童装与潮流品牌尤其常用。

  • 圆角矩形：最稳妥的异形入门，挂绳不易割纸
  • 服装轮廓：T恤、连衣裙外形，直接呼应产品品类
  • 镂空设计：内部挖空几何图形，透出织物颜色，层次感强
  • 异形对纸张克重有要求：低于 300 克易变形，建议 300 克以上

4. 出血、安全边距与打孔位

无论尺寸大小，文件规范决定成品质量。给供应商的文件请遵守以下三条，能显著减少返工：

  • 出血：四周至少 2–3mm，异形吊牌建议 3mm 以上
  • 安全边距：文字与关键图形距裁切边至少 5mm
  • 打孔位：距边缘不小于 5mm，孔径 3–4mm，与挂绳粗细匹配

5. 常见尺寸误区与选型建议

最常见的误区是「先设计后定尺寸」：设计稿做大了再压缩，字体与留白全部失衡。正确的顺序是先定尺寸，再按尺寸做设计。另一个误区是盲目追求大尺寸——信息量不大时，大吊牌反而显得空。

💡 提示：不同品类可以共用同一视觉、不同尺寸：基础款用 35×70mm 控制成本，礼盒款用 60×100mm 撑场面——同一套设计文件稍作调整即可，供应商一般都能支持。
