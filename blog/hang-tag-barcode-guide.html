服装吊牌条码指南：EAN-13、UPC 与 ITF-14 怎么选、怎么印

泰阁包装 · 更新于 2026年9月10日

吊牌上的条码，是品牌与零售系统之间的「数据接口」：进仓、上架、收银、盘点都靠它。条码印错最常见的后果不是罚款，而是门店扫不出来、整批货被打回重贴。本文讲清服装吊牌条码的类型怎么选、尺寸与静区规范、颜色和材质怎么配，以及可变数据印刷与验收要点。

先说结论：条码不是吊牌上的装饰，而是一个有严格尺寸与对比度要求的机器可读区域。设计和印刷时，它必须比 LOGO 和文案拥有更高的优先级——任何「为了好看」而缩小、调色或压在图案上的做法，都可能让整批吊牌在收银台前失效。

1. 吊牌上为什么需要条码

  • 零售结算：百货、商超与连锁店的 POS 系统按条码调取价格与库存，扫不出就只能手动输码，直接影响结账效率；
  • 仓储与物流：仓库收货、拣货、装箱、发运节点靠扫码记录，条码不清会导致收发货数据错位；
  • 电商与全渠道：平台仓、门店发货与退换货都要求商品条码唯一且可追溯；
  • 品类管理：品牌方靠条码统计 SKU 动销，条码格式不统一会让数据无法汇总。

    • 2. 常见条码类型怎么选

    条码类型典型位数适用场景
    EAN-1313 位欧盟、亚太等大多数国家零售单品，全球最通用
    UPC-A12 位美国、加拿大零售，进入北美商超通常必需
    ITF-1414 位外箱、整箱运输与仓储，常印在瓦楞纸箱上，也可做吊牌附码
    Code 128可变长度内部编码、批次与管理码，密度高、可含字母数字

    选择原则很简单：面向消费者零售的吊牌，按目标市场用 EAN-13 或 UPC-A；内部或整箱管理的附加码，用 Code 128 或 ITF-14。一个吊牌上同时出现两种码很常见，但必须分区清晰、互不干扰。

    3. 尺寸、静区与印刷质量

  • 放大系数：零售条码通常按标准尺寸的 80%–200% 放大，低于 80% 会明显增加扫读失败率；吊牌空间紧张时优先改布局，而不是压小条码；
  • 静区留白：条码左右两端必须保留空白区（一般不小于 10 倍窄条宽度），静区内不得有文字、边框、花纹或吊牌边缘；
  • 条高：条码高度不足会被收银台手持枪「扫半边」，高点位置建议保留足够条高，宁可加高不可压扁；
  • 印刷精度：条与空的边缘必须锐利、无虚边和糊版，墨色均匀；胶印、数码印刷与热转印都能做，关键在分辨率与压力控制。

    • 4. 颜色与承印材质怎么配

    条码扫描依赖红外或红光对深浅的反射差，因此颜色搭配不是审美问题，而是能否读到的问题。经验规则是「深条浅底」：黑条配白底最稳；蓝色、绿色、深棕等通常可用；红色、橙色、金色系条码在红光扫描下对比度极低，务必避免。反光覆膜会在扫描时形成高光，哑膜或未覆膜更利于扫读。

    材质方面，铜版纸、白卡纸是最稳妥的承印面；牛皮纸底色偏深、纹理明显时，建议先印一块白底再印条码；PVC 或防水吊牌要选择与之匹配的油墨，避免条码被刮花或渗色。若吊牌要经过洗水、干洗或长期日晒，条码区域的耐摩擦与耐光性需在打样阶段一并验证。

    5. 可变数据：一物一码怎么做

    当品牌需要唯一码（防伪、序列号、批次追溯）时，条码就变成可变数据印刷：每张吊牌的编码都不同，通常用数码印刷或喷码完成。要点有三：一是数据源必须是可核对的表格或数据库，印刷前逐条校验位数与校验位；二是条码与吊牌上的序列号、二维码信息保持一致，避免「码对人不对」；三是大批量可变数据处理需要提前与工厂确认排版方式（拼版数量、跳号规则、废品补印），否则错码会在整批中成片出现。

    6. 打样与验收清单

  • 向设计或客户索取矢量条码文件（AI/EPS/PDF），不要用截图或位图缩小使用；
  • 样品到手后用真实收银枪或扫码 App 实测，在不同角度与光照下各扫若干次；
  • 核对条码数值与吊牌印刷文字、系统后台是否三处一致；
  • 确认放大系数、静区、条高与颜色符合目标市场规范，并保留样品与检测记录备查。
    • 💡 泰阁提示：吊牌条码属于「一次印错、整批报废」的细节。把条码源文件、编码规则和摆放位置在打样阶段一次性确认，远比大货返工便宜。我们支持条码与二维码、烫金、序列号同版印刷，打样 3–7 天出样。
