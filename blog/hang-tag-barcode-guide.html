服裝吊牌條碼指南：EAN-13、UPC 與 ITF-14 怎麼選、怎麼印

泰閣包裝 · 更新於 2026年9月10日

吊牌上的條碼，是品牌與零售系統之間的「數據接口」：進倉、上架、收銀、盤點都靠它。條碼印錯最常見的後果不是罰款，而是門店掃不出來、整批貨被打回重貼。本文講清服裝吊牌條碼的類型怎麼選、尺寸與靜區規範、顏色和材質怎麼配，以及可變數據印刷與驗收要點。

先說結論：條碼不是吊牌上的裝飾，而是一個有嚴格尺寸與對比度要求的機器可讀區域。設計和印刷時，它必須比 LOGO 和文案擁有更高的優先級——任何「爲了好看」而縮小、調色或壓在圖案上的做法，都可能讓整批吊牌在收銀臺前失效。

1. 吊牌上爲什麼需要條碼

  • 零售結算：百貨、商超與連鎖店的 POS 系統按條碼調取價格與庫存，掃不出就只能手動輸碼，直接影響結賬效率；
  • 倉儲與物流：倉庫收貨、揀貨、裝箱、發運節點靠掃碼記錄，條碼不清會導致收發貨數據錯位；
  • 電商與全渠道：平臺倉、門店發貨與退換貨都要求商品條碼唯一且可追溯；
  • 品類管理：品牌方靠條碼統計 SKU 動銷，條碼格式不統一會讓數據無法彙總。

    • 2. 常見條碼類型怎麼選

    條碼類型典型位數適用場景
    EAN-1313 位歐盟、亞太等大多數國家零售單品，全球最通用
    UPC-A12 位美國、加拿大零售，進入北美商超通常必需
    ITF-1414 位外箱、整箱運輸與倉儲，常印在瓦楞紙箱上，也可做吊牌附碼
    Code 128可變長度內部編碼、批次與管理碼，密度高、可含字母數字

    選擇原則很簡單：面向消費者零售的吊牌，按目標市場用 EAN-13 或 UPC-A；內部或整箱管理的附加碼，用 Code 128 或 ITF-14。一個吊牌上同時出現兩種碼很常見，但必須分區清晰、互不干擾。

    3. 尺寸、靜區與印刷質量

  • 放大係數：零售條碼通常按標準尺寸的 80%–200% 放大，低於 80% 會明顯增加掃讀失敗率；吊牌空間緊張時優先改佈局，而不是壓小條碼；
  • 靜區留白：條碼左右兩端必須保留空白區（一般不小於 10 倍窄條寬度），靜區內不得有文字、邊框、花紋或吊牌邊緣；
  • 條高：條碼高度不足會被收銀臺手持槍「掃半邊」，高點位置建議保留足夠條高，寧可加高不可壓扁；
  • 印刷精度：條與空的邊緣必須銳利、無虛邊和糊版，墨色均勻；膠印、數碼印刷與熱轉印都能做，關鍵在分辨率與壓力控制。

    • 4. 顏色與承印材質怎麼配

    條碼掃描依賴紅外或紅光對深淺的反射差，因此顏色搭配不是審美問題，而是能否讀到的問題。經驗規則是「深條淺底」：黑條配白底最穩；藍色、綠色、深棕等通常可用；紅色、橙色、金色系條碼在紅光掃描下對比度極低，務必避免。反光覆膜會在掃描時形成高光，啞膜或未覆膜更利於掃讀。

    材質方面，銅版紙、白卡紙是最穩妥的承印面；牛皮紙底色偏深、紋理明顯時，建議先印一塊白底再印條碼；PVC 或防水吊牌要選擇與之匹配的油墨，避免條碼被刮花或滲色。若吊牌要經過洗水、乾洗或長期日曬，條碼區域的耐摩擦與耐光性需在打樣階段一併驗證。

    5. 可變數據：一物一碼怎麼做

    當品牌需要唯一碼（防僞、序列號、批次追溯）時，條碼就變成可變數據印刷：每張吊牌的編碼都不同，通常用數碼印刷或噴碼完成。要點有三：一是數據源必須是可覈對的表格或數據庫，印刷前逐條校驗位數與校驗位；二是條碼與吊牌上的序列號、二維碼信息保持一致，避免「碼對人不對」；三是大批量可變數據處理需要提前與工廠確認排版方式（拼版數量、跳號規則、廢品補印），否則錯碼會在整批中成片出現。

    6. 打樣與驗收清單

  • 向設計或客戶索取矢量條碼文件（AI/EPS/PDF），不要用截圖或位圖縮小使用；
  • 樣品到手後用真實收銀槍或掃碼 App 實測，在不同角度與光照下各掃若干次；
  • 覈對條碼數值與吊牌印刷文字、系統後臺是否三處一致；
  • 確認放大係數、靜區、條高與顏色符合目標市場規範，並保留樣品與檢測記錄備查。
    • 💡 泰閣提示：吊牌條碼屬於「一次印錯、整批報廢」的細節。把條碼源文件、編碼規則和擺放位置在打樣階段一次性確認，遠比大貨返工便宜。我們支持條碼與二維碼、燙金、序列號同版印刷，打樣 3–7 天出樣。
