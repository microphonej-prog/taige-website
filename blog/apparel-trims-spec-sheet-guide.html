服裝輔料規格書怎麼寫：吊牌、織嘜、洗水標與包裝袋字段清單

泰閣包裝 · 更新於 2026年9月19日

輔料訂單出問題，很少是工廠做不出來，而是規格書沒說清。同樣一句「白色棉繩吊牌」，對方可以理解成三種紙張、兩種繩子、兩種打孔位置。規格書（Spec Sheet，也叫輔料技術資料）的作用，就是在打樣前把「我們要什麼」變成可以覈對、可以追溯的文字與數字。

下面的字段順序與供應商排產順序一致：材質、尺寸、顏色、工藝、文字、數量與包裝、交期。照這個順序填寫，報價更快，打樣一次通過率也更高。

1. 規格書、輔料手冊、訂單三者分工

很多品牌把這三件事混在一封郵件裏，最後誰也說不清哪句話是最終版本。分工其實很清楚：規格書管單件、輔料手冊管成套、訂單管商務。

文件主要作用
規格書 Spec Sheet描述單件輔料的技術要求，隨詢價與打樣需求發出
輔料手冊 Trim Book彙總全系列編號、規格與封樣，品牌內部與供應商共用
訂單 PO數量、單價、交期、付款與驗收條款

三份文件共用同一套編號，改動只在規格書裏發生，訂單隻引用編號與版本號。這樣任何時候都能回答一個問題：這批貨是按哪一版做的。

2. 所有輔料都要寫清的八個通用字段

  • 品名與用途：寫「主嘜 · 領口」或「包裝袋 · 內袋」，避免同名不同用途
  • 材質與規格：紙張克重或紗線與織法、袋材厚度、織帶寬度
  • 成品尺寸與公差：成品尺寸加上公差（如 ±1mm），並註明測量方法與裁切邊
  • 顏色與色樣：Pantone 或實樣封樣，並寫清批次色差容忍範圍
  • 工藝組合：印刷方式加上後道工藝（燙金、壓凹凸、上光、模切、超聲波）
  • 文字與語言版本：中英法西日韓各版本對應哪個市場，由誰終審
  • 數量與包裝：箱裝數量、每捆數量、是否單件裝袋、混碼方式
  • 文件版本與日期：規格書編號、版本號與生效日期，改動留痕

3. 分品類字段清單與最容易漏的項

通用字段之外，每類輔料都有自己最容易漏的字段。下表是打樣前至少要確認的內容；首次合作建議連封樣一起寄，讓供應商按實樣確認。

品類必填字段最容易漏的
吊牌紙張與克重、成品尺寸與公差、孔位與孔徑、吊繩與吊粒、印刷面數、燙金部位孔位到邊距離與吊繩長度
織嘜織法（緞面 / 平紋 / 提花）、寬度與折法、切邊方式、縫製方式、經緯密度折法與切邊方式
洗水標材質（織帶 / 塗層 / 印刷）、洗滌符號版本、成分標註、語言組合、耐洗等級洗滌符號版本與語言組合
包裝袋材質（OPP / PE / CPE）、厚度、袋型與封口、印刷油墨、透氣孔與警示語警示語與透氣孔

4. 顏色與公差：把「差不多」寫成數字

顏色是輔料返工的頭號原因。吊牌紙張、織嘜紗線、紙袋面紙的上色原理完全不同，同一個 Pantone 號在三種材質上必然有差別。可行的做法是按品類分別封樣，並把允許色差寫進規格書：織嘜以封樣爲基準、參考灰卡四級到五級；紙品承認批次間輕微色差，但不得影響品牌主色識別。尺寸公差同樣要落到數字：吊牌成品尺寸按 ±0.5 到 1mm，織嘜按 ±1mm，織帶寬度按 ±0.5mm，異形模切要另外約定刀模公差。

5. 語言版本與文件版本控制

洗水標的多語言組合、吊牌上的品牌故事、包裝袋上的警示語，都需要指定「市場、語言、文案」的對應關係。建議在規格書裏用三列寫清，並註明文案由誰終審：品牌方審校，還是供應商按既有模板翻譯。不同市場的強制語言與洗滌符號版本不同，文案定稿前不要開印版，否則改版要按新印版計費。

  • 命名統一：品牌 - 品類 - 編號 - 版本 - 日期，例如 TAGE-HANGTAG-HT104-V3-20260919
  • 改動升版：每次修改升版本號，並在變更記錄裏寫清改了什麼、爲什麼、影響哪些批次
  • 封樣同步：封樣袋上貼版本標籤，避免「樣是新版、單是舊版」
  • 批次隔離：已下單批次仍按原版本生產，改版從下一批生效，不混批
  • 回執確認：發出新版時寫明「本版替代 V2」，並要求供應商回覆確認

6. 四個最常見的漏填事故與打樣前核對

💡 最容易踩的四個坑：只寫「白色」，沒寫克重與色號，首批偏黃；沒寫折法與切邊方式，織嘜裝不上領口、縫製工時翻倍；沒寫洗滌符號的語言組合，到貨後重新訂標，最快也要七到十天；沒寫包裝方式，一捆壓出摺痕，客戶倉庫收貨時會判次品。
  1. 規格書是否已升到最新版本，並附變更說明
  2. 是否附封樣或色樣，包括紙張、紗線與袋材小樣
  3. 數量與包裝方式是否與訂單一致，含單件裝袋與混碼
  4. 洗滌符號版本與語言組合是否與目標市場匹配
  5. 打樣費與交期是否已確認，以及大貨可退與否
  6. 誰做最終籤樣確認，品牌簽字還是書面郵件確認
