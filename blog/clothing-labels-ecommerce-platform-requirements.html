电商平台服装标签要求：亚马逊、TikTok Shop、SHEIN、Temu 怎么标才不被下架

泰阁包装 · 更新于 2026年9月16日

很多服装卖家在自建站卖得好好的，一上亚马逊、TikTok Shop、SHEIN 或 Temu 就被下架、扣分甚至整批拒收。原因常常不是产品，而是服装标签：平台对标签的要求往往比目的国法规更细，因为它还要用标签在后台上做货号识别和投诉溯源。

这篇指南把主流平台的服装标签要求拆开讲：平台到底在标签上看什么、吊牌与洗水标怎么分工、条码与包装袋警示语怎么处理，以及下单时该让供应商提前预留哪些位置。

1. 平台的标签逻辑：识别 + 合规 + 溯源

理解这三层，你就能预判平台会挑什么问题，而不是等被下架后再猜。

  • 识别——条码与货号让仓库和系统认出这是哪一条 SKU、哪个尺码、哪一批货（亚马逊 FNSKU、TikTok Shop SKU、SHEIN 与 Temu 的供应商货号）
  • 合规——目的国法规要求的纤维成分、护理说明、原产国、责任主体信息，平台会在上架审核或抽检时核对
  • 溯源——批次码、生产商或进口商信息，出现质量投诉时平台要能追到责任方，这也是吊牌上常被要求加编码的原因

结论很直接：平台要的不只是「合规标签」，而是「能被系统读、能被法规查、能被投诉追」的标签。规范做法是洗水标承载法定信息，吊牌承载品牌与平台编码。

2. 亚马逊：FNSKU、耐久标签与包装袋警示语

  • FNSKU 条码——入 FBA 的每一件商品都要贴亚马逊生成的 FNSKU 标；原有厂商条码必须被完全覆盖，不能两个条码同时露在外面，否则仓库扫描冲突会被判为不可售
  • 品牌与 Listing 一致——吊牌、主唛上的品牌名要与 Listing 品牌一致，避免被判「信息不符」；用英文与目标市场语言并列时，品牌名写法要统一
  • 服装合规信息——美国市场要求纤维成分、护理说明与原产国以耐久方式附着（缝制洗水标、织唛或耐久印刷），吊牌可作补充但不能替代
  • 包装袋窒息警示语——开口尺寸较大的塑料袋包装需要印上窒息警示（提示远离婴儿与儿童、不可作为玩具），缺少警示语的包装有可能在收货环节被拒收，这是服装类最容易被忽略的一条
  • 外箱箱唛——装箱后外箱要按平台要求贴箱标（含发货信息与箱内明细），混装箱与单品箱的要求不同，装箱前先确认

3. TikTok Shop、抖音电商等社交电商

  • 主体与类目报备——上架前要完成主体资质与类目报备，服装类目通常要求提供质检报告或符合性声明，报告上的品名要与吊牌、洗水标一致
  • 详情页与实物一致——短视频与商品标题里说「纯棉」，标签上就必须是 100% 棉；说「不起球」这类功能性宣称，也要有对应依据，否则会被判虚假宣传
  • 童装与内衣更严——儿童服装与贴身衣物通常涉及更高的安全类别与警示要求，标签上要留出安全类别、适用年龄等信息的位置

4. SHEIN、Temu 等平台模式：模板化的标签要求

  • 平台模板优先——这类平台通常下发固定的标签模板：供应商编号、款号、条码、尺码、成分与洗涤符号的摆放位置都有规定，改一次版面往往要重新报备
  • 先送检再上架——成分、色牢度、甲醛等项目通过后才能上架，检测样品要来自量产批次，标签上的成分必须与送检样品一致
  • 条码不可省——条码通常由平台分配或按平台规则生成，需要印刷或贴到每件商品和每个包装上；用自制条码有扫不出、被判无效的风险

5. 平台 × 标签要点对照表

平台 标签重点 高频拒收原因
亚马逊 FNSKU 条码、耐久合规标、包装袋窒息警示语、外箱箱唛 未贴 FNSKU、与厂商条码冲突、缺少窒息警示语
TikTok Shop / 抖音电商 品牌、成分、质检报告、详情页与实物一致 视频宣称与标签不符、无质检报告、类目报备未完成
SHEIN / Temu 平台标签模板、供应商货号与条码、送检合格 版面不符模板、未送检、条码无法扫描
自建站（Shopify 等） 目的国法规信息 + 退换货与联系方式 缺少进口商或欧盟责任人信息、退换货说明不清

6. 供应商侧要提前做的六件事

  1. 版面预留——下单时就告知供应商要留条码、二维码、批次码的位置，避免后期用贴纸盖住设计；预留区最好印白底，保证扫码对比度
  2. 条码打印质量——条码边缘发虚、对比度不足会扫不出，属于典型的「标签做对了但过不了关」；建议用真实条码打样并实测扫码
  3. 编码对应规则——吊牌货号、洗水标货号与平台 SKU 要能一一对应，尺码写法按目的市场习惯（US／EU／亚洲码不可混用）
  4. 印刷还是贴纸——编码稳定不变就印上去，更整齐也更省人工；编码随批次变化（如批次码、有效期）则建议留出贴纸位
  5. 包装袋与内包装——胶袋、快递袋的警示语与透气孔要一并确认，包装上的品牌信息与标签信息不要互相矛盾
  6. 留档一份「标签档案」——把每款的标签样张、条码图档、成分依据与检测报告编号归档，被抽检或被投诉时可以在几小时内答复平台
💡 提示：平台规则更新频繁，本文讲的是各家共通的逻辑与常见要求。开款前请以卖家后台的最新政策为准；如果我们按你们平台模板排版打样，请把模板文件（PDF 或截图+尺寸）一起发来，避免来回改版。

7. 泰阁可以配合什么

东莞泰阁包装主营吊牌、织唛／主唛、洗水标、包装胶袋、环保纸袋与宣传册。针对电商平台客户，我们可以按平台标签模板排版、把条码与二维码直接印到吊牌上、做可变批次码，并把纸袋、胶袋的警示语一并在打样阶段确认。OEM／ODM 与来样定制均可，打样 3–7 天，大货交期 10–25 天，起订量灵活（吊牌 2,000–3,000 张可试单，织唛 1,000 米起，洗水标 300–500 张起）。
