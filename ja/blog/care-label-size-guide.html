洗濯表示ラベルのサイズガイド：標準仕様・文字高・レイアウト計画

泰閣包装 · 2026年9月3日更新

洗濯表示ラベルのサイズは、衣料副資材の中で最も過小評価されやすいディテールです。小さすぎると繊維組成や洗濯記号が収まらず、縫い目に食い込まれます。大きすぎると肌着では肌に当たって痛く、縫製時に変形します。さらに厄介なのは、輸出用ラベルの問題が検品や店頭投入の段階になって初めて発覚することが多い点です。この洗濯表示ラベルのサイズガイドでは、仕様・文字高からレイアウト計画までを解説し、サイズを一度で正しく決められるよう支援します。

1. まずタイプと取り付け方式を決め、その後にサイズを検討する

洗濯表示ラベルには主に3つの形態があり、サイズの考え方がそれぞれ異なります。織りテープ洗濯表示ラベルは幅が織機に制約され、標準は 15mm、20mm、25mm（10mm と 30mm もあります）で、長さは内容に応じて 50〜90mm の間で裁断し、脇縫いなどの直線的な縫い位置に適します。コーティング／印刷洗濯表示ラベルと熱転写洗濯表示ラベルは織機の幅制約がなく、35×60mm、40×70mm のような長方形にも、極細の帯状にもでき、後ろ中心の襟ぐりやウエストなどに適します。まず縫製工場と取り付け方式と縫い位置の長さを確認し、そこから逆算してラベルサイズを決めるのが最も確実な順序です。

2. 文字高の基準：適合性と耐洗濯性の両立

洗濯表示ラベルの一文字一文字は、数十回の洗濯・乾燥・摩擦に耐えなければなりません。実務上の目安は、ラテン文字（英語・フランス語など）の高さは 1.5〜2mm 以上、中国語は 2〜2.5mm 以上を推奨し、洗濯記号は ISO 3758（GINETEX）の標準比率で作成し、スペースを節約するために勝手に圧縮してはなりません。コンプライアンス面では、米国 FTC はケアラベルが永続的で明確に読み取れることを求め（16 CFR 423）、EU の繊維規則は繊維組成ラベルが耐久性があり、読みやすく、見え、手に取れることを求めています。文字高はデザインの好みではなく、コンプライアンスと体験の最低ラインです。

💡 ヒント：折り畳みは見える文字高を「目減り」させます——二つ折りにするとラベルの厚みが倍になり、厚地に縫い付けると文字が押し広げられて変形します。折った後も 1.5〜2mm の有効文字高を確保する必要がある場合は、設計上の文字高をそれに応じて大きくしてください。

3. 内容が行数を決め、行数がサイズを決める

内容項目標準的な行数説明
ブランド名／LOGO1 行表面に配置するか、メインラベルと統合できます
繊維組成1〜2 行成分が4種類を超える場合は2行配置を推奨
洗濯記号群1〜2 行記号は ISO 3758 の比率で完全に作成する必要があります
原産地／輸入者／RN 番号1〜3 行米国市場では RN 番号を含めることで工場名・住所を伏せられます
ケア説明の短文1〜3 行「漂白不可」「つり干し」など
言語が1つ増えるごとに+2〜3 行多言語輸出（EU など）ではレイアウトの余裕を確保する必要があります

見積もり方法は簡単です。内容を1行ずつ書き出し、行数の上限を数えます。内容が3行以内なら、単層または二つ折りで足ります。3行を超える場合は、通常は織りテープを長くするか、多ページ折り（ブックレット式）に変更する必要があります。そうでなければ文字高を犠牲にするしかありません——それは先ほど犠牲にできないと述べたものです。

4. 折り方と長さの計画

  • 二つ折り（Center fold）：製品長さは裁断長さの約半分で、最も一般的な縫製形態であり、内容が 3〜6 行のラベルに適します
  • 端折り（End fold）：両端を中央に向けて折ってから縫うため、切り口が見えず、繊細な外観が求められる高級衣料に適します
  • ブックレット式（Booklet）：Z 字または C 字の多ページ折りで、1折り増えるごとに長さがほぼ倍になり、多言語・長文の輸出用ラベルに適します
  • 長さ計画の原則：裁断長さ = 製品の可視長さ × 折り数 + 縫い代の余裕。織りテープが長いほど単価が上がり縫製難度も高まるため、必要な分だけに留めます

5. 衣料品目別のサイズ推奨

品種推奨形態ポイント
Tシャツ／シャツ二つ折り織りテープ 20×50〜60mm脇縫いに装着し、柔らかく肌に当たりません
デニム／ワークパンツロング織りテープ 25×70〜90mm内容が多く水洗いも頻繁なため、耐摩耗性が必要です
子供服二つ折り 15×40〜50mm短く柔らかくし、肌との摩擦を避けます
アウター／ダウンブックレット式またはロングテープ多言語／長いケア説明に対応し、裏地の縫い位置に十分なスペースがあります
インナー／スポーツウェア熱転写またはコーティングラベル極薄で無感覚ですが、文字高の厳密な検証が必要です

6. よくある誤解とサンプル確認

  • 誤解1：全品目で同じ洗濯表示ラベルサイズを使う。アウターと子供服ではサイズと柔らかさの要件がまったく異なるため、品目ごとに仕様を定めるべきです
  • 誤解2：文字を縫い目の端まで配置する。縫い代が 3〜5mm を占めるため、四周に必ず安全マージンを確保してください
  • 誤解3：先にデザインを確定してから位置を探す。正しい方法は、縫製工場に縫い位置の長さと折り形態を先に確認してもらい、それに基づいてデザインを確定しレイアウトすることです

サイズの問題はサンプルでしか担保できません。サプライヤーに 3〜7 日で実物サンプルを依頼し、目標の生地に実際の縫い位置で装着し、標準に従って5回洗濯して、文字が明確で、収縮や変形がなく、ほつれがないことを確認します。量産の寸法公差は通常 ±2mm に管理し、封緘サンプル後に「封緘サンプルの寸法 + 公差」を契約に明記すれば、量産がぶれることはありません。
