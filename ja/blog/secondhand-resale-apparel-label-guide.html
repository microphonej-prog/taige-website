中古・リセール衣料のラベルガイド：洗濯表示・サイズ・等級タグ

泰閣包装 · 2026年10月13日更新

中古衣料とリセール事業の最初の壁は、仕入れではなくラベルです。一度流通に戻ってきた衣類は、洗濯表示が色あせ、サイズラベルが外れ、タグは失われていることが多く、中古プラットフォーム・レンタル会社・アウトレット倉庫・セレクトショップのいずれも、検品と出品の基準にその情報を使います。中古衣料のラベルは、古着が良い値段で売れるか、在庫の廃棄物になるかを分けます。

本ガイドは5部構成です。リセールとレンタルで最も止まりやすい3つのラベルの課題、補うべき6種類の副資材、繰り返しの洗濯とドライクリーニングに耐えるラベルの選び方、適合要件とプラットフォーム要件の境界、最後に6段階のリフレッシュと格付けの流れを示します。

1. リセールとレンタルで最も止まりやすい3つの課題

  • 洗濯表示の色あせ・欠落：洗濯とドライクリーニングを重ねると、コーティングラベルの印字が摩耗します。組成と手入れ方法が見えないと、一件ずつ説明が必要になり、返品も増えます。
  • サイズラベルと現物の不一致：旧ラベルが外れた、書き換えられた、洗濯で縮んだなどで、表示サイズが信用できません。リセールで最も避けたいのがサイズ紛争で、実寸の方が信頼できますが、それでもラベルには一貫したサイズ基準が必要です。
  • 追跡できる識別情報の欠如：チャネルは品番・サイズ・状態等級・ロットを必要とし、レンタル事業者は耐久性と手入れ履歴も必要とします。これらを担う副資材がなければ手作業の記録に頼ることになり、規模が大きくなると破綻します。

2. 中古・リセール品で補うべき6種類の副資材

張り替えとは異なり、中古品では交換ではなく「補充と再構築」です。下表で6種類の副資材、リセール工程での役割、作り直す際に最も注意すべき点を並べます。

副資材リセールでの役割作り直す際の要点
洗濯表示ラベル有効な組成と手入れ方法を示し、中古品の信頼の土台になります縮み・仕立て直し・裏地交換の後は、新しいラベルの内容が現物と一致するか必ず確認します
サイズラベル一貫した基準で絞り込めるようにし、サイズ紛争を減らします実寸と併用します。ラベルは一つのサイズ基準、詳細ページは実測サイズ、両者が矛盾しないようにします
タグと等級札ブランド・状態等級・サイズ・価格を担い、中古品唯一の新しい顔になります状態等級は社内基準を統一し、担当が変わっても判定がぶれないようにします
社内 ID ラベル品番・入荷ロット・洗濯回数やレンタル回数を結び、棚卸しと責任追跡を可能にします位置を統一し、洗濯に強く、印字が落ちないこと。レンタル品はドライクリーニングに強い素材を優先します

3. 繰り返しの洗濯に耐えるラベルの選材

リセールとレンタルのラベルは、新品基準ではなく洗濯回数を基準に選びます。レンタルでは1着が1年に十数人の手に渡ることもあり、ラベルの耐久性が手直しの頻度を決めます。

  • 織りテープの洗濯表示：文字を帯に織り込み、繊維そのもので発色させるため洗濯と摩擦に強く、高頻度のレンタルやスポーツ品に最適です。代わりに細部は粗く、色数も限られます。
  • コーティング印刷の洗濯表示：印字が鮮明で情報量が多く、組成表や多言語表記に向きます。耐摩耗コーティングを選び、量産前に実際の洗濯劣化試験で印字の持ちを確認します。
  • ドライクリーニングと耐熱性：レンタルのドレス・スーツ・コートはドライが基本なので、溶剤に耐える素材が必要です。プレスが前提の品はラベルもアイロン温度に耐えなければ、端が縮れて硬くなります。
  • 縫い付けが寿命を決めます：両端を返し縫いし適度な縫い目にする方が、接着や熱圧着より長持ちします。リセール品は次のメンテで再び解ける縫い方を優先します。
  • 色と移染リスク：濃色生地に淡色ラベルを付けるとラベルが染まり、淡色生地に濃色ラベルを付けると色移りすることがあります。生地とラベルを一緒に洗濯試験する方が、後から説明するより安く済みます。

4. 適合要件とプラットフォーム要件：硬い線と自社判断の線

中古品やリフレッシュ品は、多くの市場で「中古だから免除」とはなりません。繊維組成・手入れ方法・原産地・製造者または輸入者情報といった基本要素は、転売時にも提示できる必要があります。適用範囲は国ごとに異なるため、新品の旧ラベルを流用せず、対象市場の公式説明で確認してください。

  • 真贋が最優先：ブランド表示・セキュリティ部品・産地説明を、売れ行きのために曖昧にしてはいけません。中古チャネルは模倣品混入への許容度が極めて低く、一度の事故で出品資格を失いかねません。
  • リフレッシュと修理は正直に表示：裏地の交換、装飾の補修、サイズ直しは、商品説明やラベルに明記し、「新品」「未使用」と誤認させないようにします。
  • デジタル製品パスポートの方向性：EU は繊維のデジタル情報と循環経済の要件を進めており、将来的に組成・産地・手入れ情報の照会が求められる可能性があります。品番・ロット・素材データを今から構造化して記録しておく方が、後から埋めるよりはるかに楽です。
  • プラットフォーム規約は法規より細かいことが多い：状態等級の用語、サイズの入力方法、旧ラベルの写り込み可否、手入れ情報の撮影要否などは各社で異なります。出品前に対象プラットフォームの最新規約を項目ごとに確認すれば、下架トラブルを大幅に減らせます。

5. 6段階のリフレッシュと格付けフロー

  1. 入荷検品：品番・サイズ・入手チャネル・初期状態を記録し、洗濯表示の有無と判読可否を確認します。ここで補う副資材が決まります。
  2. クリーニングと整え：品目ごとに洗濯・ドライ・部分処理の工程を分け、処理後は寝かせて水分を戻してから形を整えます。水染みを残さないためです。
  3. 修理と張り替え：ほつれの縫い直し、スライダー交換、ボタンの補修を行い、洗濯表示・サイズラベル・社内 ID を一度に補完して二度手間を防ぎます。
  4. 基準に沿った格付け：外観・摩耗・色味・欠品の項目で等級定義を文書化し、等級ごとに基準写真を用意します。担当間の判定差を防ぐためです。
  5. 札付け・撮影・出品：等級に応じてタグと等級札を付け、実寸・手入れ方法・難の位置を商品説明に記載します。情報が揃うほど返品が減ります。
  6. 包装と発送：品目に応じた包装（防塵袋・再封可能袋・硬質箱）を選び、手入れと返品の案内を同梱して、輸送じわによるトラブルを減らします。
💡 ヒント：中古事業の副資材は「再使用」を前提に設計します。張り替えのたびに社内 ID の位置・縫い付け方・手入れ記録を同じルールに揃えておけば、3回目のメンテで一件ずつ対応せずに済みます。
