衣料副資材の輸出 HS コードと通関ガイド：タグ・織りラベル・包装

泰閣包装 · 2026年9月15日更新

衣料副資材の HS コード（関税商品コード）は、輸入関税率、規制条件、追加証明書の要否を決定します。タグ、織りラベル、洗濯表示ラベル、ポリ袋、紙袋はどれも小さな付属品に見えますが、申告時には異なる類に分かれることがあります。同じラベルでも紙製・織物製・プラスチック製では別の類に入り、同じ貨物でも衣料品に付けた状態と単独で輸出する状態では分類が変わる場合があります。分類を誤ると、軽ければ追徴課税、重ければ検査による滞留につながります。

本記事では、分類の考え方 → 主要な変数 → 書類リスト → FTA 優遇税率の順に、副資材の輸出通関で最もよく生じる問題を整理します。

1. 副資材の HS コードを適当に記入してはいけない理由

HS コードは国際共通の6桁に、各国が細分を加える体系です。最初の6桁は世界共通で、以降は各国が独自に規定するため、同じ商品コードでも中国、EU、米国、日本では末尾が異なります。通関時に1桁を誤ると、税率がゼロ関税から2桁台に変わったり、反ダンピングや割当規制を誤って発動させたりすることがあります。

副資材の購買担当者にとって、コードは 原産地証明書 を活用できるか、FTA の優遇税率を適用できるか、そして輸入国税関が成分検査や環境声明の提出を求めるかにも関わります。

2. 代表的な衣料副資材の分類の考え方

下表は、一般的な副資材が通常どの類／号に入るかを示したもので、社内での初期判断と通関業者との打ち合わせにご利用ください。最終的な分類は中国税関の現行税率表および税関の認定によります——同じ商品でも成分、加工方法、包装が異なれば号が変わる場合があります。

副資材通常の類／号の方向分類のポイント
紙製タグ（印刷）第48類 紙および紙製品（印刷ラベル）印刷の有無が号を決定し、無印刷の白カードは別の号に分類されます
織りラベル / メインラベル第58類 特殊織物（ラベル、ワッペン）織物の成分（綿／化合繊）で末尾が細分されます
洗濯表示ラベル（印刷テープ）第58類 または第59類（コーティング／ラミネート織物）コーティングや箔層があると分類は第59類に移ります
ポリ袋（PE／OPP／CPE）第39類 プラスチックおよびその製品（袋類）ポリエチレンとその他のプラスチックは末尾が分かれます
エコ紙袋第48類 紙袋（袋底の幅で細分）袋底の幅が一般的な区分線です
パンフレット / カタログ第49類 印刷物（商業カタログ類）広告品は一般書籍やチラシとは別の号に分類されます

レザーラベル / レザーパッチ第42類 革製品本革と再生革／PU は別の類に分類されます
💡 ヒント：副資材はセットの形で衣料品と一緒に出荷されることがよくあります。タグ、織りラベル、ポリ袋を同じ段ボールに詰めて1つの品名で申告する場合は、項目別申告が必要かどうかを先に通関業者へご確認ください——混合申告は検査時に分類の係争が最も起きやすい部分です。

3. 分類を左右する4つの主要変数

  • 材質——紙、織物、プラスチック、金属、皮革はそれぞれ別の類に属し、最初の判断基準となります
  • 印刷の有無——印刷の有無によって、同じ材質の商品が別の号に入ることがよくあります
  • 小売包装かどうか——ロール巻き、バラ積み、小売用小包装では分類が異なる場合があります
  • 機能性——帯電防止、難燃、偽造防止チップなどの特殊機能は追加の規制条件を招く場合があります

4. 通関書類チェックリストとよくある誤り

通常の輸出書類一式には、商業送り状（品名、数量、単価、総額、貿易条件）、パッキングリスト（個数、毛重量・純重量、容積）、申告要素（材質、成分、規格、加工方法、ブランド）、契約書、および必要に応じて原産地証明書が含まれます。このうち申告要素は最も見落とされやすく、かつ分類に最も影響する項目です。

  • 品名に labels や tags とだけ書き、紙製・織物製・プラスチック製の区別がない——検査につながる最も多い原因です
  • 織りラベルに繊維混率の記載がなく、税関が綿製か化合繊製かを判断できません
  • 数量単位の混用（枚／ロール／ダース／キログラム）でパッキングリストと一致しません
  • 送り状金額と申告金額が一致しない、またはサンプル作成費・版代の申告漏れがあります

5. 原産地証明書と FTA 優遇関税

中国で生産した副資材を、ASEAN、オーストラリア、ニュージーランド、韓国、日本など RCEP 加盟国、および自由貿易協定を締結済みのその他市場へ輸出する場合、通常は原産地証明書により優遇税率を申請できます。要点は3つです。貨物の号が協定の譲許表に含まれていること。原産地規則（完全生産品または地域内付加価値基準の充足）を満たすこと。証明書の種類が仕向国に適合していること（一般原産地証明書 CO、RCEP 原産地証明書、中国・オーストラリア／中国・韓国などの専用様式）。

EU、米国など中国と自由貿易協定を締結していない市場については、最恵国税率、反ダンピング措置、そして輸入国のラベル・環境法規要件（包装材のリサイクル性、化学物質規制など）に注意が必要です。これらは HS コードには影響しませんが、円滑な通関可否に影響します。

6. 副資材サプライヤーと確認すべきチェックリスト

  • 見積書には品名だけでなく、推奨 HS コードと申告要素を明記するようサプライヤーに依頼します
  • 原産地規則の判定に用いるため、織りラベルと洗濯表示ラベルの繊維混率を確認します
  • 到着港での追加書類要求を避けるため、成分検査や REACH／CPSIA 声明などの支援書類を事前に依頼します
  • 多品種の混載時は材質ごとに箱を分け、それぞれに明記して項目別申告を容易にします
  • 長期取引では、HS コードを含む自社の副資材コード表を作成し、再発注時にそのまま使用します
