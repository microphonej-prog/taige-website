UVカット衣料のラベルガイド：UPF等級・洗濯後の保持・適正表示

泰閣包装 · 2026年10月8日更新

紫外線カット衣料の売りは、最終的に1枚のラベルに集約されます。タグに UPF 等級をどう記載するか、洗濯表示に必要か、洗濯後も維持できるかは、いずれも実際のコンプライアンス課題です。UPF は好きなだけ高く表示できる数値ではなく、対象市場の試験方法・等級のしきい値・表示ルールを満たす必要があります。テストレポートなしに UPF 50+ を表示すると、欧米のECプラットフォームでは簡単に削除されます。

本記事は5部構成です。まず UPF の等級と試験方法、次に市場ごとの表示方法、洗濯後の維持、UV カット衣料の副資材の選び方、最後にタグと包装での伝え方とコンプライアンスチェックリストを示します。

1. UPF とは：等級・試験方法・しきい値

等級 紫外線透過率 一般的な表示 補足
UPF 15～24 約 1/15～1/24 Good UV protection 入門レベルの保護
UPF 25～39 約 1/25～1/39 Very good 中程度の保護
UPF 40～50+ ≤1/40 Excellent／UV カット製品 主流のしきい値
UVA 透過率 5% 未満が必要 UPF 値と同時に満たす 中国と欧州の必須条件

試験方法は市場ごとに異なります。米国は AATCC 183 と ASTM D6603、EU は EN 13758-1 で試験し EN 13758-2 で表示、豪州・NZ は AS/NZS 4399、中国は GB/T 18830 です。同じ UPF 値でも方法が違えば同等とは限らず、市場を変える場合は再試験か同等性の説明が必要で、そのまま流用はできません。

2. 表示のしかた：市場ごとに書き分ける

  • 米国：FTC は UPF 表示に試験の裏付けを求め、UPF 50+ が表示の上限で、それ以上の数値は記載できません。
  • EU：EN 13758-2 が UV カット衣料のラベル記載事項と UPF 50+ の表現方法を定めています。
  • 豪州・NZ：AS/NZS 4399 の UPF 50+ が小売で最も多く求められるしきい値です。
  • 中国：GB/T 18830 は UPF 40 超かつ UVA 透過率 5% 未満でのみ UV カット製品と称することができ、表示は繊維製品の取扱い表示規定にも適合する必要があります。
  • プラットフォーム：Amazon などは通常テストレポートの提出を求め、未提出や表示の不一致は即削除につながります。

3. 洗濯後の維持：ラベルと洗濯方法の書き方

UV 性能は織物密度・繊維・後加工に由来し、洗濯・伸張・湿潤で低下します。ラベルが洗濯前の値か洗濯後の値かは、試験の口径と一致していなければ、良い製品でも誤認表示と判断されます。

  • 洗濯後の UPF：初期値か、規定回数の洗濯後の保持値かを明記し、両者を混用しません。
  • 伸張と湿潤：湿った状態や伸ばした状態では UPF が下がります。高密度で濃色の生地は比較的安定します。
  • 洗濯表示：冷水の弱洗いを指定し、漂白と高温乾燥を避けて UV 加工の流失を抑えます。
  • 「永久に UV カット」「絶対防護」など検証不能な断定表現は避けます。規制当局もプラットフォームも誤認表示として扱います。
💡 ヒント：UV 加工の保持力は生地と染色加工で決まり、タグとは関係ありません。製品の洗濯表示に書かれた条件で洗濯後の UPF を検証してから、初期値か保持値かを決めます。順序を逆にしないでください。

4. UV カット衣料の副資材の選び方

  • ファスナー、縫い糸、テープ、メッシュ、表地が全体の UV 性能を決めます。UV 生地に大きなメッシュを開けて UPF 50+ を表示することはできません。
  • 濃色の副資材は一般的に UV 劣化に強く、淡色の縫い糸やファスナーテープは日光で早く劣化します。
  • フードコードやドローコードは、EN 14682 などの子供服のひも安全要件と UV 設計の説明を同時に満たす必要があります。
  • 副資材そのものが UV カットをうたう場合は、独自の試験の裏付けが必要で、表地のレポートを流用することはできません。

5. タグと包装で UV の訴求を伝える

  • タグには UPF 等級、試験方法、レポート番号を記載でき、断定表現は避けます。
  • 洗濯表示とタグの情報は一致させ、食い違う場合はより保守的な表現を採用し双方を修正します。
  • 包装内に UV ケアカードを入れると、正しい洗濯方法を案内し、UV 性能の寿命を延ばせます。
  • コンプライアンスチェックリスト：テストレポート、表示の口径、市場の言語、責任者情報の4点を輸出前に確認します。
